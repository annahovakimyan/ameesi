# Golden charts

Reference charts with known correct results. The engine must match each within 1 arcminute (0.0167°).

## How to add a chart

1. Pick a birth with a reliable time (your own, family members' with permission, or public figures rated AA on Astro-Databank).
2. On astro.com, create the chart with the same settings: tropical zodiac, Placidus houses, true node.
3. Copy the positions into `charts.csv`, one row per chart, longitudes as decimal degrees (for example 22°14′ Leo = 120 + 22 + 14/60 = 142.233).
4. Note the source and the UTC offset astro.com used, so disputed historical offsets can be checked.

Aim for variety: several Soviet-era Armenian births (before 1991), dates around daylight-saving changes, one birth above 66° latitude, southern-hemisphere births, and a leap day.

Personal birth data here is public, since the repository is public. Only add charts with the person's consent, or of public figures.
